# Escape-The-Code
Programa de sala de escape para Algoritmia 1 de Uade 
• Nombre del equipo: PyWarriors
• Nombre del Escape Room: Escape the code
• Temática: Backrooms/Terror
• Breve historia del escape room: Sos un programador que está trabajando en su casa y cuando vas al baño y cerras la puerta, sentís que te caes. Sin darte cuenta estás en otra habitación, una oficina, sin puertas ni ventanas. Allí escuchas un ventilador de fondo, y al voltearte ves una computadora vieja estilo de los 90 con un mensaje que dice “Hello World!”.
	
Te acercas a la computadora, apretas enter y te aparece un ahorcado. 

URL Github: https://github.com/joaquingil15/Escape-The-Code.git
